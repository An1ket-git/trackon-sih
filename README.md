# TrackOn - AI-Powered Bus Tracking System

## Smart India Hackathon 2025 | Problem Statement ID: 25013

### Live Demo
**Website URL:** https://an1ket-git.github.io/trackon-sih/

### Problem Statement
60% of commuters in tier 2/3 Indian cities face unpredictable bus schedules and digital exclusion. Existing solutions fail non-smartphone users and lack accurate predictions.

### Our Solution
TrackOn provides:
- Real-time bus tracking with AI-powered ETA predictions
- Crowd density indicators for better travel planning
- SMS notifications for non-smartphone users
- Offline-first design for low-connectivity areas
- Interactive route planning interface

### Technology Stack
- Frontend: HTML5, CSS3, JavaScript
- Mapping: Leaflet.js with OpenStreetMap
- Icons: Font Awesome
- Hosting: GitHub Pages

### Key Features Demonstrated
1. Interactive map with route visualization
2. Bus stop locations and information
3. Route selection interface
4. Responsive design for all devices
5. SIH-specific branding and documentation
